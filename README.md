# technix8.0
## Technix 8.0 — Flagship Cyber Tournament & Defense Operations Suite
### Target Audience: MCA & Postgraduate Computer Science Symposium

---

## ⚡ Overview

**Technix 8.0** is an end-to-end, zero-dependency, tournament-grade cybersecurity competition package featuring four progressive operational rounds. Designed for high technical integrity, realistic cyber defense simulation, and seamless lab deployment without external hosting dependencies.

---

## 🚀 Quick Launch Instructions

Each interactive round (`Round1_System_Reconnaissance/index.html`, `Round2_Phishing_Webmail/index.html`, `Round4_Capture_The_Flag/index.html`) is **fully standalone**:
1. Clone or download this repository.
2. Double-click any `index.html` file in Google Chrome, Microsoft Edge, Firefox, or Brave.
3. No local web server, node, python, or database installation is required for student workstations.
