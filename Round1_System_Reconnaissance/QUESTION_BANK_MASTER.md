* **Question:**  
  Which modern cybersecurity architectural model is built on the core principle of 'Never Trust, Always Verify', enforcing strict identity and authorization checks for every access request regardless of origin?
  * [A] Defense-in-Depth Model
  * [B] Zero Trust Architecture (ZTA)
  * [C] De-Militarized Zone (DMZ)
  * [D] Bastion Perimeter Security
* **Correct Answer:** **[B] Zero Trust Architecture (ZTA)**
* **Technical Rationale:** Zero Trust Architecture (ZTA) eliminates implicit trust, requiring continuous authentication and least privilege.
